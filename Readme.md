# Sedona

Двухстраничный сайт туристического городка Седона. Проект реализован с использованием методологии БЭМ.
Если убрать в html класс, то модальное окно скроется. 

## 🗂 Страницы

- **Главная страница** (`index.html`) - визитная карточка городка
- **Страница каталога** (`catalog.html`) - гостиницы и достопримечательности
- **Модальное окно** - форма поиска гостиницы

## 🛠 Технологии и особенности

### HTML
- Семантическая верстка
- Методология БЭМ для именования классов
- Формы с валидацией (инпуты, селекты)
- Модальное окно с формой поиска

### CSS
- Flexbox для построения сеток
- CSS-переменные для единой системы стилей
- Анимации и переходы:
  - Плавное изменение цвета при наведении на иконки
  - Эффекты hover для кнопок и карточек
- Стилизация состояний элементов (:hover, :focus, :active)
- Обработка переполнения контента (overflow)
